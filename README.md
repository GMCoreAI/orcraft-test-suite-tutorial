# Orcraft tutorial suite

The test suite the [Orcraft tutorial](https://orcraft.app/tutorial/) builds, step by step, against the Maze application. Every code example on the tutorial pages appears here, so you can follow along in the same project, run it and inspect what happens.

## Groups

- Intro
- Basic Configuration Parameters
- Advanced Configuration Parameters
- Statuses and Results
- Structure and Lifecycle
- Endpoints

The entry point is `test_suite_tutorial.py`.

## Using it

1. Install Orcraft and add this suite to the controller as the [Getting started](https://orcraft.app/setup/getting-started/) guide shows.
2. Download the Maze application releases the tutorial names, as the [Maze application](https://orcraft.app/tutorial/maze-application/) page shows. Some tests fetch the release list from the public GitHub API themselves.
3. Register the endpoints the tutorial asks for, see [Adding endpoints](https://orcraft.app/setup/endpoints/).
